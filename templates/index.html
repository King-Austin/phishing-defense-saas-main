Methodology

Classification is performed using a Logistic Regression model trained on TF-IDF vectorized text. The system evaluates semantic patterns and token frequency to differentiate between legitimate communications and phishing attempts.

System Features

The implementation features real-time classification, probability-based confidence scoring, and a feedback loop for model evaluation. Features are extracted using stop-word filtering and N-gram analysis.
