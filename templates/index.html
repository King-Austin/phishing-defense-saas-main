Project Overview

Academic Research & Implementation

A technical defense project focused on the application of neural networks in cybersecurity.

Methodology

The system utilizes TF-IDF vectorization and supervised learning models to evaluate the distribution of tokens within an email. By training on the CEAS and Nigerian Fraud datasets, the model identifies semantic indicators of social engineering, payload delivery, and fraudulent intent.

Core Technical Features

  • NLP-Based Tokenization: Extracts high-dimensional features from raw email text.
  • Binary Classification: Employs probability-based classification for threat detection.
  • Performance Metrics: Evaluated against standard accuracy, precision, and recall benchmarks.
  • Scalable Architecture: Built on a Flask-based microservice architecture for real-time inference.
